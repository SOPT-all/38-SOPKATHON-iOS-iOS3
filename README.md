## Key Features 🔑
- **온보딩을 통한 서비스 메시지 전달**
  - 실수를 부끄러운 실패가 아니라 기록할 가치가 있는 성장의 시작으로 인식할 수 있도록 안내합니다.

- **실수 순간 기록**
  - 사진과 한 줄 메모로 실수의 순간을 빠르게 기록할 수 있습니다.

- **홈에서 기록 확인**
  - 오늘의 실수 기록 여부, 누적 개수, 최근 카드를 한눈에 확인할 수 있습니다.

- **실수 앨범 및 회고 관리**
  - 쌓인 실수 카드를 그리드 형태로 모아 보고, 회고 여부에 따라 다른 흐름으로 실수를 관리할 수 있습니다.
  - 아직 회고하지 않은 카드는 회고 작성 화면으로 이동해 회고 내용과 감정을 기록할 수 있습니다.
  - 회고가 완료된 카드는 실수 기록과 작성한 회고, 선택한 감정을 함께 확인할 수 있습니다.
  
- **회고 완료 카드 애니메이션**
  - 회고를 저장하면 카드가 뒤집히는 애니메이션과 함께 완료 상태로 전환되어, 실수가 배움으로 정리되는 순간을 직관적으로 보여줍니다.

## Tech Stack ⚒️

```
SnapKit    : 코드 기반 UI 구현 시 오토레이아웃을 보다 간결하고 직관적으로 설정하기 위함
Then       : 클로저 기반 인스턴스 초기화를 통해 UI 컴포넌트 설정 코드를 간결하게 작성하기 위함
Moya       : 네트워크 요청을 추상화하여 API 통신 코드를 구조적으로 관리하고 유지보수성을 높이기 위함
Kingfisher : 이미지 URL 로딩, 캐싱, 비동기 처리를 간편하게 구현하여 이미지 처리 성능을 향상시키기 위함
```

## Convention 💥
### Tag (PR, Issue, Commit)
|Tag|사용하는 부분|
|:---:|:---:|
|[feat]|기능 구현 시 사용합니다.|
|[style]|UI 구현 시 사용합니다.|
|[add]|사진 등 에셋이나 라이브러리 추가 시 사용합니다.|
|[fix]|버그나 오류 해결 시 사용합니다.|
|[docs]|리드미, 템플릿 등 문서 수정 및 주석 추가 시 사용합니다.|
|[refactor]|기존 코드를 성능 개선 등의 이유로 리팩토링했을 때 사용합니다.|
|[delete]|기존 코드나 파일을 삭제했을 때 사용합니다.|
|[setting]|프로젝트 관련 설정 변경 시 사용합니다.|
|[chore]|기타.|
